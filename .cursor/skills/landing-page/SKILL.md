# Landing Page

Use with `frontend-design` for visuals. This skill owns **structure and persuasion flow**.

## Page spine (default order)

1. **Hero** — Brand, promise, CTA, dominant visual (see frontend-design hero rules)
2. **Proof or product** — What it is / why it matters (one section, one idea)
3. **Details** — Features, menu, process, or offer — still one job per section
4. **Social proof** — Reviews or trust (only if real content exists; never fake)
5. **Final CTA** — Repeat the primary action with urgency or clarity
6. **Footer** — Essentials only (nav, contact, legal)

Skip sections that lack real content. Empty placeholders hurt more than a shorter page.

## Copy rules

- Headline = outcome or desire, not feature list
- Supporting line ≤ 1–2 sentences
- CTA verbs are specific (“Pedir ahora”, “Ver menú”) not vague (“Enviar”, “Click aquí”)
- One primary CTA per viewport; secondary links stay visually quieter

## Section checklist

For each section:

- [ ] Single H2 (or equivalent) with one purpose
- [ ] No duplicate CTAs fighting each other
- [ ] Visual or whitespace creates breathing room
- [ ] Works without relying on card grids unless interaction needs a card

## Conversion hygiene

- Primary CTA reachable in ≤ 1 scroll on mobile
- Contact / order paths obvious in header or hero
- Forms: few fields, clear labels, visible errors
- No autoplaying sound; video only if it strengthens the promise

## Anti-patterns

- Hero packed with stats, schedules, addresses, and promos
- Multiple competing offers above the fold
- Fake testimonials or placeholder Lorem in final polish
- Endless feature grids with icons and no hierarchy
